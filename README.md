This program searches (in vain) for a solution to the 3x3 Magic Square of Squares
problem using the Magic Triples approach described at:
https://www.solutionslookingforproblems.com/post/searching-for-a-3x3-magic-square-of-squares.

Thus far, it has not produced anything close to a solution, so it's main value is in showing
how much it has searched.
